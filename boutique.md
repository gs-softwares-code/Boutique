# Luxury Fashion Boutique — Complete Website Development Prompt

Act as an award-winning fashion brand creative director, premium UI/UX designer, and senior full-stack developer.

Build an elegant, luxurious, production-ready website for a fashion boutique. The website should communicate exclusivity, craftsmanship, personal styling, and sophisticated fashion.

The result must feel like a high-end designer boutique rather than a generic clothing e-commerce website.

## 1. Visual Identity & Design

**Design Direction:** Contemporary Luxury Boutique / Editorial Fashion.

- Color palette: Warm ivory, champagne beige, soft blush, espresso brown, and elegant black.
- Typography: Cormorant Garamond or Playfair Display for headings; Inter for body text.
- Editorial-style fashion photography.
- Large immersive image sections.
- Elegant product layouts.
- Minimal navigation.
- Sophisticated hover effects.
- Smooth scrolling and subtle animations.
- Premium spacing and refined compositions.
- Fully responsive mobile-first design.
